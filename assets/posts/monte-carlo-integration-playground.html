The curve and the reference value

Here we use a curve whose integral we can calculate, so we can compare our estimate with the answer.

Here, a = 0, b = 4, and c = 1.2, so the rectangle area is 4.8 square units. With t = x / 4, the curve is

f(x) = 0.18 + 0.50 exp(−((t − 0.28) / 0.12)²) + 0.30 exp(−((t − 0.74) / 0.18)²) + 0.07 sin²(6πt).

Each exponential and sin² term is between 0 and 1, so 0.18 ≤ f(x) ≤ 1.05 < c. The reference integral is 1.6601700413794354 square units, evaluated from the Gaussian error function and the sine antiderivative, independently of the sampled points. All displayed decimals are rounded.

Samples come from a seeded pseudorandom generator. Reset returns to one sample and preserves the sequence; New random run changes it. The count and estimate use every sample; the scatter plot displays at most the first 5,000 points to stay readable.
